# 🎬 Media Tracker — Telegram Bot

Клієнтська частина проєкту **Media Library**, реалізована у вигляді асинхронного Telegram-бота на Python (`aiogram 3`). Бот взаємодіє з REST API бекендом на C# (.NET) для управління особистою колекцією фільмів, серіалів та ігор з ізоляцією даних кожного користувача через JWT-авторизацію.

## 📂 Структура проєкту

* `main.py` — точка входу, ініціалізація бота, диспетчера, middleware, глобального обробника помилок та підключення роутерів.
* `api_client.py` — асинхронний HTTP-клієнт (`httpx`), моделі даних (`pydantic`), обмін `X-Bot-Api-Key` на JWT через `POST /api/auth/bot` та кешування токенів окремо для кожного користувача.
* `middlewares.py` — `AuthMiddleware`, який бере реальний Telegram ID із `from_user.id` і прив'язує запити до конкретного користувача.
* `keyboards.py` — генератори базових Inline-клавіатур.
* `menu.py` — обробники головного меню, статистики, довідників жанрів/тегів та перевірки статусу сервера.
* `media.py` — CRUD-операції з медіатекою: пагінація списку, фільтрація, картка запису, зміна статусу/оцінки, нотатки та історія сесій перегляду.
* `create_search.py` — FSM-сценарії для ручного додавання записів та зовнішнього пошуку (TMDB / RAWG) з імпортом.
* `test_api.py` — автоматизовані unit-тести на `pytest` із мокуванням запитів через `httpx.MockTransport`.

## ⚙️ Вимоги

* **Python** 3.11 або новіший
* Запущений сервер **MediaLibrary.Api** (локально за замовчуванням `http://localhost:5021`) із налаштованими секретами `Jwt:Secret` та `BotAuth:ApiKey`

## 🚀 Інструкція із запуску

### 1. Створення віртуального оточення та встановлення залежностей

```powershell
cd bot
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Налаштування змінних оточення (`bot/.env`)

Створи файл `bot/.env` (він не додається в Git) та заповни параметри:

```env
BOT_TOKEN=твій_токен_від_BotFather
API_BASE_URL=http://localhost:5021
BOT_API_KEY=спільний_ключ_від_32_символів_такий_самий_як_BotAuth:ApiKey_на_API
```

> **Важливо:** `BOT_API_KEY` має бути окремим секретом (не `BOT_TOKEN` і не `Jwt:Secret`) довжиною щонайменше 32 UTF-8 байти. Для продакшену `API_BASE_URL` має використовувати `https://`.

### 3. Запуск бота

```powershell
python main.py
```

## 🧪 Запуск тестів

Із папки `bot/` з активованим `(venv)`:

```powershell
pytest -v
```
