# 🎬 Media Tracker — Telegram Bot

Клієнтська частина проєкту **Media Library**, реалізована у вигляді асинхронного Telegram-бота на Python (`aiogram 3`). Бот взаємодіє з REST API бекендом на C# (.NET) для управління особистою колекцією фільмів, серіалів та ігор.

## 📂 Структура проєкту

* `main.py` — точка входу, ініціалізація бота, диспетчера та підключення роутерів.
* `api_client.py` — асинхронний HTTP-клієнт (`httpx`) для взаємодії з C# API та моделі даних (`pydantic`).
* `keyboards.py` — генератори базових Inline-клавіатур.
* `menu.py` — обробники головного меню, статистики (`/stats`), довідників жанрів/тегів та перевірки статусу сервера.
* `media.py` — CRUD-операції з медіатекою: пагінація списку, фільтрація, перегляд картки, зміна статусу/оцінки, нотатки та сесії перегляду.
* `create_search.py` — FSM-сценарії для ручного додавання записів та зовнішнього пошуку (TMDB / RAWG) з імпортом.

## ⚙️ Вимоги

* **Python** 3.11 або новіший
* Запущений локально сервер **MediaLibrary.Api** (за замовчуванням на `http://localhost:5021`)
